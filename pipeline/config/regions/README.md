# Regiões de comparação do atlas

Caixas `[oeste, sul, este, norte]` em graus, uma lista por variável do atlas.

**Estado: proposta, a aprovar pela Ciência** (`docs/03`, secção 5). As caixas da temperatura
vêm do protótipo; as da precipitação reutilizam as caixas do protótipo com nomes geográficos
e acrescentam o Sahel. Não atravessam o antimeridiano.
